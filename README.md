# 📱 我的工作台 — 使用说明

一个运行在 iPhone 上的个人工作台,包含 **任务管理、日程安排、图片去水印** 三大模块。
全部数据仅保存在手机本地,图片处理全程本地完成,**不上传任何服务器**。

---

## 🚀 如何安装到 iPhone

### 方式一:本地部署(推荐,无需服务器)

1. 在电脑上启动本地服务器(已运行):
   ```
   http://127.0.0.1:8000
   ```
2. 让 iPhone 和电脑连**同一个 Wi-Fi**,在 iPhone 的 Safari 浏览器中访问:
   ```
   http://<电脑IP>:8000
   ```
   > 电脑 IP 查看方法:电脑终端运行 `ipconfig`,找"IPv4 地址"(形如 `192.168.1.x`)。
3. 点击 Safari 底部 **分享按钮** → 选择 **"添加到主屏幕"** → 确认。
4. 回到主屏幕,点开"工作台"图标,即可全屏使用,像原生 App 一样。

> ⚠️ 注意:此方式需要电脑保持开机并运行服务器。若关掉电脑,已缓存的页面仍可离线使用,但新增数据无法保存到手机(见方式二)。

### 方式二:部署到免费托管(长期使用,推荐)

把项目文件夹上传到任意静态托管平台(如 **GitHub Pages / Vercel / Netlify / Cloudflare Pages**),获得一个公开网址后:
1. iPhone Safari 打开该网址
2. 分享 → "添加到主屏幕"
3. 之后任何时候、任何网络都能使用,数据永久保存在手机

## 📋 任务管理

| 操作 | 方法 |
|---|---|
| 添加任务 | 右下角 **➕** 按钮 → 输入名称、选优先级、设截止日期、写备注 |
| 完成打勾 | 点击任务左侧圆圈 |
| 编辑任务 | 点击任务文字区域 |
| 删除任务 | 点击任务右侧垃圾桶图标 |
| 切换视图 | 顶部"今日 / 全部"选项卡 |

- 顶部卡片实时显示**今日进度**和完成比例
- 截止日期自动显示"今天/明天/昨天/已逾期"

## 🗓️ 日程安排

| 操作 | 方法 |
|---|---|
| 切换月份 | 左上/右上箭头 |
| 查看某天 | 点击日历上的日期 |
| 添加日程 | 下方"添加日程"按钮(自动带入所选日期) |
| 编辑/删除 | 点击日程卡片 / 点击垃圾桶 |

- 日历上的**彩色圆点**表示当天日程(蓝=工作、绿=生活、橙=个人),**红点**表示有待办任务
- 选中日期会联动显示当天的任务和日程

## 🧽 图片去水印

1. 进入"去水印"页 → 点 **选择图片**(从相册或拍照)
2. 在图片上**拖拽框选**水印区域(可框选多个,每次框完自动进入选择模式)
3. 对选中的区域选择处理方式:
   - ✨ **智能修复**:用周围画面内容自动填充(适合纯色/平滑背景,效果最自然)
   - 🌫 **模糊**:把区域模糊掉(适合复杂背景)
   - ✂ **裁剪选区**:直接裁出选区为新图
4. **导出 PNG(无损)**:1:1 原始分辨率、零压缩导出
   - 也支持导出高质量 JPG(质量 95%)
5. 导出后在预览页**保存图片**(或长按图片保存到相册)

**质量保证:**
- ✅ 输出保持**原始分辨率**,像素级还原
- ✅ 仅框选区域被处理,画面其他部分**逐点原样保留**
- ✅ 全部在 iPhone 本地完成,图片不上传
- ✅ 支持撤销(↩)、多区域处理

> 💡 提示:水印压在**纯色/平滑背景**上效果最好;若水印压着人物、景物等复杂纹理,建议用"模糊"或尝试缩小选区多次修复。

## 📂 项目结构

```
wo/
├── index.html           主页面
├── manifest.json        PWA 配置(图标、名称)
├── sw.js                Service Worker(离线缓存)
├── css/style.css        样式(深色模式适配)
├── js/
│   ├── storage.js       本地存储 + 工具函数
│   ├── tasks.js         任务模块
│   ├── calendar.js      日程模块
│   ├── watermark.js     去水印模块(FMM 智能修复算法)
│   └── app.js           主控制器
└── icons/               应用图标(180/192/512)
```

## 🔒 隐私说明

- 任务、日程数据保存在 **iPhone 本地 localStorage**,不联网
- 去水印图片**全程本地处理**,绝不离开手机
- 无任何统计、广告、第三方请求
